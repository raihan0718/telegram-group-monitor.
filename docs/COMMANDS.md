# Bot commands

| Command | Akses | Fungsi |
|---|---|---|
| `/help` | Semua | Daftar perintah |
| `/report` | Semua | Ringkasan anggota dan pesan tercatat |
| `/top` | Semua | 10 anggota teraktif |
| `/inactive` | Semua | Tidak mengirim pesan dalam INACTIVE_DAYS |
| `/candidates` | Admin | Di bawah MIN_MESSAGES |

Daftar kandidat hanya untuk pemeriksaan admin. Tidak ada pengeluaran anggota otomatis.
